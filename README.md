# 🐱 Рыжий Том X — RPG MEGA Edition

Мобильная игра для GitHub Pages / iPhone.

## Новое в RPG MEGA
- 🗺️ большой мир с 6 локациями
- 🌲 лес: ресурсы и случайные находки
- 🎣 озеро: рыбалка
- ⛏️ шахта: руда и кристаллы
- 🏙️ город: NPC, дружба и репутация
- ⚔️ арена с боссом
- 🌾 ферма с посадкой, поливом и сбором урожая
- 🥚 спутники: лисёнок, зайчик, щенок
- 📈 прокачка спутника
- 👕 гардероб и покупка одежды
- 🐭 улучшенная мини-игра с видимой мышью
- 🏥 болезни и лечение
- 💾 сохранение прогресса в localStorage
- 📱 адаптация под iPhone

Главный файл: `index.html`.
